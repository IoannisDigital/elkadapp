# ΓΕΜΗ OpenData → Excel ανά ΚΑΔ

Αυτόνομο εργαλείο Python που αντλεί δημόσια στοιχεία επιχειρήσεων από το
**OpenData API του ΓΕΜΗ** και παράγει ένα **ξεχωριστό αρχείο Excel (`.xlsx`) ανά ΚΑΔ**,
με **ένα φύλλο (tab) ανά Νομό** και ένα φύλλο **«Σύνοψη»**.

Σκοπός: νόμιμες B2B προτάσεις συνεργασίας (**όχι** spam).

## Πεδία ανά επιχείρηση
Επωνυμία, ΑΦΜ, Διεύθυνση, Πόλη, ΤΚ, Νομός, Τηλέφωνο, Email, Website.

## Εγκατάσταση

```bash
pip install -r requirements.txt
```

Απαιτείται Python 3.11+.

## API key

Το κλειδί διαβάζεται από τη μεταβλητή περιβάλλοντος `GEMI_API_KEY`, αλλιώς
χρησιμοποιείται το ενσωματωμένο default.

```bash
export GEMI_API_KEY="το_κλειδί_σου"
```

## Χρήση

### 1) Αναζήτηση ΚΑΔ με λέξη-κλειδί

```bash
python gemi_pull.py search ΚΟΜΜΩΤΗΡ
python gemi_pull.py search ΑΙΣΘΗΤΙΚ
python gemi_pull.py search ΦΑΡΜΑΚ
python gemi_pull.py search ΚΑΛΛΥΝΤΙΚ
```

Τυπώνει όλους τους ΚΑΔ των οποίων η περιγραφή περιέχει τη λέξη, ώστε να βρεις
τον σωστό 8ψήφιο κωδικό πριν την εξαγωγή.

> **Προσοχή:** ο παλιός ΚΑΔ κομμωτηρίων/αισθητικής `96020000` επιστρέφει πλέον
> 404 (άλλαξε η ταξινομία σε `kad_2026`). Βρες τον τρέχοντα κωδικό με τη
> `search` και βάλ' τον στο `KADS`.

### 2) Εξαγωγή σε Excel

Άνοιξε το `gemi_pull.py` και ρύθμισε τις μεταβλητές στην ενότητα
**«ΡΥΘΜΙΣΕΙΣ ΠΟΥ ΑΛΛΑΖΕΙΣ ΕΣΥ»**:

- `KADS` — λίστα με τους ΚΑΔ που θέλεις (παράγεται **1 xlsx ανά ΚΑΔ**).
- `PREFECTURES` — `"ALL"` για όλη την Ελλάδα, ή λίστα με ονόματα
  (π.χ. `["ΘΕΣΣΑΛΟΝΙΚΗΣ", "ΑΤΤΙΚΗΣ"]`) ή κωδικούς (π.χ. `["19", "5"]`).
- `PRIMARY_ONLY` — `True` για να κρατηθούν μόνο εγγραφές όπου ο ΚΑΔ-στόχος
  είναι **Κύρια** δραστηριότητα (καθαρή λίστα, χωρίς θόρυβο).
- `EXCLUDE` — λίστα αποκλεισμού brand/αλυσίδων (case-insensitive, «περιέχει»).

Έπειτα τρέξε:

```bash
python gemi_pull.py
```

Τα αρχεία δημιουργούνται στον φάκελο `output/` με όνομα
`GEMH_<ΚΑΔ>_ana_Nomo.xlsx` (π.χ. `output/GEMH_47730000_ana_Nomo.xlsx`).

## Καθαρισμός δεδομένων

- **PRIMARY_ONLY**: κρατά μόνο εγγραφές με τον ΚΑΔ ως Κύρια δραστηριότητα
  (`type == "Κύρια"` και `activity.id` ξεκινά με τα 4 πρώτα ψηφία του ΚΑΔ).
- **EXCLUDE**: αποκλεισμός αλυσίδων ενός brand (επεκτάσιμη λίστα).
- **Διπλότυπα**: αφαιρούνται με βάση το ΑΦΜ.

## Μορφή αρχείων Excel

Κάθε αρχείο περιέχει:

- Φύλλο **«Σύνοψη»** πρώτο: Νομός / Πλήθος (φθίνουσα), με γραμμή **ΣΥΝΟΛΟ**.
- Ένα φύλλο (tab) **ανά Νομό** με τις στήλες:
  Επωνυμία, ΑΦΜ, Διεύθυνση, Πόλη, ΤΚ, Νομός, Τηλέφωνο, Email, Website.
- Όνομα φύλλου ≤ 28 χαρακτήρες, με καθαρισμό των `: \ / ? * [ ]` και μοναδικότητα.
- Επικεφαλίδα έντονη, φόντο `#1F3864`, λευκά γράμματα, freeze της πρώτης γραμμής.

## Όριο ρυθμού (rate limit)

Το API επιτρέπει **~8 αιτήματα/λεπτό**. Ο κώδικας βάζει `time.sleep(7.8)` ανά
σελίδα και χειρίζεται το HTTP 429 με αναμονή ~9 δευτ. + επανάληψη.

Μεγάλοι ΚΑΔ σε όλη την Ελλάδα (π.χ. Φαρμακεία `47730000` ≈ 19.746 εγγραφές,
Καλλυντικά `47750000` ≈ 39.547) μπορεί να χρειαστούν **40–90 λεπτά** — άφησέ το
να τρέξει μέχρι το τέλος.

## API — τεχνικές λεπτομέρειες

- **Base URL:** `https://opendata-api.businessportal.gr/api/opendata/v1`
- **Επιχειρήσεις:** `GET /companies`
  (`activities`, `prefectures`, `isActive=true`, `resultsSize` ≤ 200, `resultsOffset`)
- **Λίστα ΚΑΔ:** `GET /metadata/activities`
- **Λίστα Νομών:** `GET /metadata/prefectures` (55 νομοί)
- **Αυθεντικοποίηση:** header `api_key: <ΚΛΕΙΔΙ>` (ή `?api_key=...`).

## Σημείωση για εκτέλεση σε απομακρυσμένο/cloud περιβάλλον

Αν το τρέξεις μέσα σε περιορισμένο περιβάλλον (π.χ. cloud sandbox με egress
policy), ο host `opendata-api.businessportal.gr` μπορεί να μπλοκάρεται.
Σε αυτή την περίπτωση τρέξε το εργαλείο **τοπικά** στον υπολογιστή σου, όπου
υπάρχει κανονική πρόσβαση στο διαδίκτυο.
